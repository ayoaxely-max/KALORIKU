Memeriksa dukungan sinkronisasi…

Mengunggah menimpa revisi cloud sebelumnya, tetapi tidak pernah otomatis. Jika perangkat lain telah mengubah cloud, unggah akan ditolak. Mengunduh menampilkan penggabungan berdasarkan ID dan pilihan konflik sebelum konfirmasi. Setelah digabung, unggah hasilnya agar perangkat lain menerima gabungan terbaru. Backup JSON lokal tetap disarankan. Perbarui semua perangkat ke versi 2.13.1; aplikasi lama tidak dapat membaca cadangan baru.

Data & backup

Pengingat muncul di dashboard jika belum ada backup atau sudah 7 hari. Tanggal dicatat setelah Anda mengonfirmasi file tersimpan.

Data utama disimpan pada perangkat ini. Backup JSON mencakup catatan makan, air, berat badan, profil, produk sendiri, foto, favorit, paket, resep, dan takaran khusus. Export CSV untuk laporan, bukan pemulihan.

Cara pindah perangkat
  1. Di perangkat lama, tekan Backup JSON dan periksa file di Unduhan.
  2. Kirim file JSON ke perangkat baru, misalnya melalui Drive, kabel, atau WhatsApp sebagai dokumen.
  3. Di perangkat baru, buka KaloriKu dan perbarui aplikasi. Pilih Periksa & pulihkan backup JSON.
  4. Pilih file, periksa ringkasan, lalu tekan Ganti data dengan backup. Ini mengganti data yang sudah ada pada perangkat tujuan; buat cadangan terlebih dahulu.
  5. Periksa riwayat makan, air, berat badan, dan foto sebelum menghapus data perangkat lama.

Pengaturan AI dan kunci sinkronisasi perlu diatur kembali. Jangan bagikan backup kepada orang yang tidak Anda izinkan.

Takaran khusus
Kolom kosong memakai takaran database bila tersedia. Takaran lain tidak diasumsikan. Resep lengkap perlu kalkulator resep.


Kalkulator resep
Perubahan menghitung ulang gizi resep di database. Catatan asupan lama tetap memakai nilai saat dicatat. Bahan memakai data gizi yang tersimpan pada resep; hapus lalu pilih ulang bahan untuk memakai data terbaru.
Pilih bahan sesuai kondisi saat ditimbang (mentah atau matang). Tambahkan minyak, gula, dan saus yang ikut dimakan. Berat matang mengubah konsentrasi per 100 g, bukan total energi. Ini estimasi dari database, belum memperhitungkan kehilangan zat gizi saat memasak.
