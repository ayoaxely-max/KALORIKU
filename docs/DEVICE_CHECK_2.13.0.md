# Pemeriksaan HP KaloriKu 2.13.0

Gunakan perangkat dan data uji sendiri. Jangan hapus data browser perangkat utama.

1. Android Chrome / iPhone Safari: buka tautan, periksa panduan awal dan tombol pemasangan. Pasang shortcut, tutup browser, lalu buka dari ikon layar utama.
2. Kamera: Ambil foto membuka input kamera; Galeri membuka pemilih foto. Batal memilih tidak menyimpan catatan. Periksa foto, tanggal, porsi dan konfirmasi asupan.
3. Offline: setelah aplikasi pernah terbuka lengkap, aktifkan mode pesawat. Buka kembali, tambah catatan, tutup dan buka ulang. Barcode yang tersimpan tersedia; produk baru memerlukan internet.
4. Backup: tekan Backup JSON. Pastikan file benar-benar ada di Unduhan sebelum File sudah tersimpan. Tutup konfirmasi tanpa menekannya: tanggal backup tidak berubah.
5. Pemindahan: kirim JSON sebagai dokumen. Pada perangkat uji kedua, perbarui KaloriKu lalu pilih pemulihan. Periksa pratinjau, pulihkan, dan bandingkan riwayat makan, berat, air, foto, produk sendiri, favorit, paket, resep dan takaran. Jangan hapus perangkat lama sebelum cocok.
6. Barcode: cari produk tersimpan berdasarkan nama/kode. Koreksi dari label dengan angka untuk takaran yang sama. Catatan makan lama tetap memakai angka sebelumnya; catatan baru memakai koreksi.
7. Pembaruan: Profil > Periksa pembaruan. Setelah diterapkan, pastikan versi dan seluruh catatan tetap tersedia.
8. Pengingat: tanggal backup terkonfirmasi tampil pada Profil. Dashboard mengingatkan bila belum ada backup atau telah tujuh hari; tidak ada notifikasi di luar aplikasi.

Catat jenis HP, browser, versi aplikasi, langkah, hasil yang diharapkan dan hasil sebenarnya bila ada kegagalan. Pemeriksaan ini membutuhkan HP nyata dan belum dijalankan oleh pengujian otomatis.
