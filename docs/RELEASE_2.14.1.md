# KaloriKu 2.14.1

- Dialog porsi menampilkan tombol ukuran rumah tangga bila konversi gram tersedia dari data makanan atau takaran pribadi. Gram tetap dapat diubah; ml tidak otomatis dianggap gram.
- Status backup membandingkan revisi data lokal dengan revisi saat file dibuat. Perubahan setelah ekspor tetap ditandai meskipun pengguna baru mengonfirmasi file kemudian. Pengingat tujuh hari tetap tersedia.
- Kartu makanan dan pratinjau porsi membedakan nilai nol dari gizi yang belum diketahui. Kalori/makro tidak lengkap dan hasil perkalian yang tidak terbatas ditolak sebelum pencatatan.
- Tidak mengubah nilai gizi katalog atau menebak angka yang hilang pada data lama.

Validasi: uji unit, integrasi DOM/IndexedDB, regresi barcode/backup dan transaksi foto otomatis. Kamera dan tampilan Chrome HP fisik belum diuji pada perubahan ini.
